# M21 one sentence, one card

One fixture. Sentence mode and classic mode. Neither pastes model text.
Esc leaves the projection and writes no sidecar. Enter keeps the define
only when the proposal scores strictly higher. The comment stays.

```bash
bash scripts/smoke_m21.sh
```

The script runs the native Aura binary. It does not call docker.
It does not call the network. It prints `PAD_M21_OK`.

## Hands-on

The fixture is `soft/pad/fixtures/propose_ok.txt`. The page is the
hello define that returns 4, with the comment `;; keep this` above it.
The proposal returns 5. That is higher. A proposal that returns the
same 4 is not kept. `SAY` is `that one is not better`.

Sentence mode is the line the launcher opens. An unknown sentence still
says `aura cannot change this page yet`. This step does not turn that
sentence into the fixture. Once the fixture proposal has raised the
card, the sentence keys drive it. Esc (byte 27) leaves the projection
byte for byte and writes no `.aw`. Enter (byte 13) on keep writes the
new define and leaves `;; keep this`.

Classic: `PAD_CLASSIC=1`. `M-x rewrite kinder` enters the same card
through `pad:tx-propose!`. It does not call `pad:ai-set-text!`. Byte 27
drops. Byte 13 keeps only when the score is strictly higher. `h`, `j`,
`k`, and `l` say `finish this card first` until the card is finished.
