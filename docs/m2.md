# M2 — MiniMax proposes a keymap pack, Soft gates, KEEP / DROP

Soft does not speak HTTP. `scripts/propose_minimax.py` (host, python3)
reads `~/.config/aura-build/minimax.env` (`MINIMAX_API_KEY_FILE`,
`MINIMAX_BASE_URL`, `MINIMAX_MODEL`, default `MiniMax-M3`). Base URL is
`https://api.minimax.cn/v1`; a configured `api.minimaxi.com` is rewritten
to `api.minimax.cn`. The key is never in the repo and never printed.

The script writes one line `(lambda () (list step room strict))`. Soft
cleans it, gates it, swaps it into `pd:law`, and races it against
`pd:shadow` (the current main) on the same 24 seeded keys.

```bash
bash scripts/smoke_m2.sh          # fixtures only → PAD_M2_PROPOSE_OK
bash scripts/smoke.sh             # M0+M1+M2 + optional live + fixture burn → PAD_SMOKE_OK
PAD_LIVE=0 bash scripts/smoke.sh  # force PAD_M2_PROPOSE_LIVE_SKIP
bash scripts/burn.sh              # 3 MiniMax rounds if a key exists, else fixtures
PAD_PROPOSE=0 bash scripts/burn.sh  # offline fixtures → PAD_BURN_OK
python3 scripts/propose_minimax.py --check   # exit 0 key present / 3 none
```

## Gate (Soft, `soft/pad/hot.aura`)

Rejected before swap (`GATE reject reason=gate word=<w>`): not a
`(lambda ...)`, too short/long, or contains `set!`, `vector-set!`,
`display`, `write`, `mutate`, `eval`, `load`, `shell`, `http`,
`read-file`, `set-code`, `fiber:`, `hot-strategy`, `pd:law`, `pd:shadow`,
`pad:live`, `pad:stamp`, `pad:race`, `pad:reset`.

Swapped, then healed, when the probe `(pd:law)` is not a valid pack
(`propose_heal`).

## KEEP rule

`KEEP` only when `trial > base`. Lower or equal → `heal!` the pre-trial
snapshot and `DROP` (`lower-score-rollback` or
`tie-is-not-better-rollback`). A kept body becomes `*main-body*` and the
next round's `pd:shadow`.

gate-rejects it honestly instead of skipping it.

## 中文

M2：主机脚本调用 MiniMax（api.minimax.cn）提出一个键位参数包
`(lambda () (list step room strict))`。Soft 门卫先查禁用词（`set!`、
`display`、`eval`、`load`、`shell`、`http` 等），再 `swap!` 进 `pd:law`
和当前主线 `pd:shadow` 比分。只有严格更高才 KEEP；相等或更低就
`heal!` 回滚并 DROP。固定样例：更差 -2 DROP，更好 10 KEEP（主线 9）。
