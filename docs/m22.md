# M22 two proposals

One sentence asks for two ideas. The card marks the higher score.
Before a single-idea KEEP, SAY names the define the change touches.
A tie writes nothing. Enter on the lower score leaves the page.
The log has one honest WORLD line.

```bash
bash scripts/smoke_m22.sh
```

The script runs the native Aura binary. It does not call docker.
It does not call the network. It does not call `intend`.
It prints `PAD_TX_TWO_OK`, `PAD_TX_WORLD_OK`, `PAD_TX_BLAST_OK`,
`PAD_TX_TIE_OK`, `PAD_TX_WORSE_OK`, and `PAD_M22_OK`.

## Hands-on

The fixture is `soft/pad/fixtures/propose_two.txt`. Idea A is
`(lambda (x) (+ x 2))` with `check hello 3 5`. Idea B is
`(lambda (x) (+ x 0))` with the same check. On the hello page, A
scores 1 and B scores 0. The card opens on A:

```text
> a   b
```

Move `>` onto b. Sentence mode uses KEY right. Classic mode uses
byte 9. Enter (byte 13) says `that one is not better`. The projection
bytes do not change. `;; keep this` stays, and so does
`(define (hello x)`.

Enter while A is marked splices

```text
(define hello (lambda (x) (+ x 2)))
```

and leaves the comment. A reversed pair, B then A, marks b first
(`a   > b`), because the higher score is not the first line of the file.

## Tie

`soft/pad/fixtures/propose_tie.txt` gives both ideas score 1. SAY is
`neither is better`. Neither `(+ x 2)` nor `(+ 2 x)` is written.
The decision uses the host scores, not whichever fiber joined first.

## Blast and the race

Before KEEP of one better idea, SAY is `touches hello`. The log is
`BLAST names=hello calls=1/1`, the same count as `query:calls`.
A mismatch says `TX_DISAGREE` and leaves the projection. Arrow keys
do not ask `query:calls`.

The two-idea race logs one line, either
`WORLD line=fiber_live` with `joins=2/2`, or
`WORLD line=host-sequential`. Both children have the same scores
either way. The key loop does not race.

## What this step does not do

It does not call `intend`. It does not add a hidden key that keeps
the lower score.
