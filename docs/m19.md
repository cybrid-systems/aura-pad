# M19 projection

The page is the projection. `query:code` is the canonical program in
the check's child workspace. A comment stays on the page and in the
file. It is not part of that canonical program.

```bash
bash scripts/smoke_m19.sh
```

The script runs the native Aura binary. It does not call docker.
It prints `PAD_M19_OK`.

## Fixture

`soft/pad/fixtures/greet.aura` is a module. It has a comment, a
multi-line `greet` define, and an em dash. The em dash bytes are
`e2 80 94`. The fixture is not a `.aw` sidecar.

## Clean save

Open the fixture and save it without an edit. The file bytes match
the bytes from open, including the em dash.

`bash scripts/smoke_m19.sh` printed `CHECK open=ok`, `CHECK dash=bytes`,
`CHECK save=saved`, and `CHECK clean=same`.

## Comment, then check

Edit the comment and check again. The new comment stays in the
projection, the define under it is unchanged, and `SAY` is
`nothing is dirty`. The check log is not the page text:

```text
READ query:code=differ proj=121 code=108
```

`proj` is the projection length. `code` is the length of `query:code`.
They are not equal. The canonical program stayed 108 bytes while the
comment grew, because the comment is not in `query:code`.

Saving that edit changes only the comment line. The em dash on that
line is still `e2 80 94`. The run printed `CHECK proj=kept`,
`CHECK say=nothing is dirty`, and `CHECK dirty-save=saved`.
No `.aw` file is written.

## Hands-on

`aura-pad` on `soft/pad/fixtures/greet.aura` opens on the sentence
line. Tab moves to that line.

Save with no edit: `save`, Enter, `quit`, Enter. Compare the file
with the copy from before the open. There is no difference. The em
dash is still its original UTF-8.

Open it again. Change the words in the comment line. Leave the em
dash. Tab, then Enter on the empty line. `SAY` says `nothing is dirty`.
The comment is still on the page. The log line `READ query:code=differ`
is not the page text.

Tab, `save`, Enter. Only that comment line differs. The em dash is
still `e2 80 94`. A folded `-` in its place would fail the compare.
