# M3.5 — finer editor commands, world undo, tests

M3.5 polishes the M3 multi-line editor. It adds nine kid-friendly commands
with their own refusal reasons, a three-line second goal for the
command-helper race, a world **undo of a KEEP**, clearer TAPE / SCORE /
REJECT lines, and a test layer (paren check, Python model, Soft unit
tests). M0–M3 scores are unchanged; M3.5 is mostly additive files.

```bash
bash scripts/smoke_m35.sh             # PAREN_OK, PAD_MODEL_OK, PAD_TEST_OK, PAD_M35_OK (+ live if keyed)
PAD_LIVE=0 bash scripts/smoke_m35.sh  # no HTTP, PAD_M35_LIVE_SKIP
bash scripts/smoke.sh                 # M0..M3 + M3.5 → PAD_SMOKE_OK
python3 scripts/edit_model.py undo type:hi indent   # score one goal3 plan on the host
python3 scripts/propose_minimax.py --helper3 out/h3.lambda 1 note   # one live goal3 helper
```

## Edit state (`soft/pad/edit.aura`)

An edit state is `(L line col kill mark undo)`:

- `L`, `line`, `col` — the M3 lines and point.
- `kill` — the last killed or copied text, as segments (a list of lines;
  a killed newline is two empty segments). One slot, no ring rotation.
- `mark` — `()` or `(line col)`.
- `undo` — snapshots `(L line col)`, newest first, at most 8.

`pad:egate` / `pad:eapply` / `pad:eop` are pure, so scoring is still safe
inside fibers. A refused command never changes the state and never pushes
an undo snapshot. Every text change (typing, `back`, `kill-line`,
`open-line`, `yank`, `indent`, `dedent`, `kill-region`) pushes one undo
snapshot and clears the mark. Moves, `set-mark` and `copy-region` do not.

| command | does | refused with |
|---------|------|--------------|
| `undo` | take back the last text change (text + point) | `nothing-to-undo` |
| `yank` | paste the kill text at point (multi-line ok) | `nothing-to-yank`, `need-space` (line > 12 or > 4 lines) |
| `indent` | two spaces at the start of the line, point moves with the text | `need-space` |
| `dedent` | remove up to two leading spaces | `no-indent` |
| `bob` / `eob` | start / end of the whole buffer | `already-there` |
| `set-mark` | mark the point | `already-there` (mark is already here) |
| `kill-region` | cut between mark and point into the kill text | `no-mark`, `empty-region` |
| `copy-region` | copy between mark and point, text unchanged | `no-mark`, `empty-region` |
| `kill-line` | as M3, and now fills the kill text | as M3 |

All M3 commands still gate the M3 way (`too-far`, `no-line`, `empty-buf`,
`need-space`, `not-print`, `not-a-key`). `home` / `end` keep M3 behaviour
so M3 helper scores stay 27 / 31.

## Clearer lines for kids

- `REJECT ... say="nothing to take back yet"` — every reason has a short
  kid sentence (`pad:kid-say` in `lines.aura`); M3 REJECT lines get it too.
- `REJECTS kind=helper total=5 shown=4` when more refusals happened than
  the four printed.
- `SCORE total=45 start=60 keys=-15 rejects=-0 dist=-0 say="15 keys, 0 oops, 0 letters off"`
  after every TAPE (M3 too) — where the points went.
- M3.5 `TAPE ... text=hi|..aura|pad view=hi|..aura|pad^ kill=nwn undo=8`
  — spaces shown as `.`, `^` is the cursor.

## Goal 3 helper race (`soft/pad/m35_smoke.aura`, `fixtures/m35/`)

Goal: `"hi"` / `"  aura"` / `"pad"` from the same seeded `nwn`. Score
`60 - keys - 2*rejects - 3*dist`. `helper.aura` now scores through hooks
(`*helper-score-fn*`, `*helper-audit-fn*`, `*helper-stamp-fn*`); M3 keeps
the 2-line defaults, `pad:helper-use-goal3!` points them at `pad:esim`.
The hooks are plain closures and fibers still join (`joins=10/10`).

| step | result |
|------|--------|
| main `main.lambda` (no indent) | `MAIN helper start=28`, dist 6 |
| `pd:helper-undo!` with nothing kept | `REJECT ... cmd=helper-undo`, world untouched |
| `bad.lambda` (`define`) | `GATE reject word=define` |
| `ugly.lambda` (`#t` token) | `HEAL reason=probe why=bad-token` |
| `worse.lambda` | REJECT `nothing-to-undo`, `nothing-to-yank`, `no-mark`, `no-indent` (+`already-there`), 11 → DROP |
| `undo.lambda` (types `auraa`, `undo`) | 43 → KEEP |
| `region.lambda` (`set-mark end kill-region`) | 43 tie → DROP |
| `best.lambda` (`indent`) | 45 → KEEP |
| `pd:helper-undo!` ×2 | `UNDO from=45 to=43`, `UNDO from=43 to=28`, each re-played and re-scored (`want=` must match) |
| `pd:helper-undo!` again | `REJECT nothing-to-undo` |
| `best.lambda` again | `RACE base=28 trial=45` KEEP |

`KEEPS=3 DROPS=2 UNDOS=2`, `WORLD line=fiber_live backend=2 joins=10/10`,
`PAD_M35_OK`.

**World undo** (`pd:helper-undo!` in `helper.aura`): each KEEP pushes the
main it replaced (body, score), at most 8. Undo pops it, points both hot
slots back at that body, re-plays the plan and re-stamps the world. If
the re-score differs from the recorded score it prints `UNDO_FAIL`.

`m35_test.aura` covers, for every new command, a REJECT path (the kid
reason, and the plan player skips it: same state, 0 keys, 1 reject) and a
success path from hand-built multi-line states; 34 plans shared with the
Python model (view + reject count; `edit_model.py --check` also fails if
the Soft table drifts from `expect.json`); caret/dot views, `kid-say` for
all 12 reasons, the SCORE line, goal3 fixture scores straight from
`pad:esim`, and M3 scores (27 / 31) unchanged. `smoke_m35.sh` fails if
the check count drops below 150. Mutation check: setting `*undo-max*` to
7 makes 4 checks fail (`PAD_TEST_FAIL`).

## Live (MiniMax-M3, measured 2026-10-05)

`--helper3` asks for a goal3 helper with the new command words and
pre-checks the shape. First run:
`"type:hi" "kill-line" "next-line" "open-line" "indent" "type:aura" "open-line" "next-line" "type:pad"`
→ `REJECT reason=no-line cmd=next-line say="there is no line there"`,
`RACE helper base=28 trial=-7`, DROP + heal, `PAD_M35_LIVE_OK`. The
Python model gives the same `-7`.

On a live KEEP, `m35_live.aura` also undoes it and requires main to be
back at 28. Run 2 (full `smoke.sh`):
`"kill-line" "type:hi" "open-line" "next-line" "type: aura" "open-line" "next-line" "type:pad"`
(one space instead of `indent`) → `RACE helper base=28 trial=30`, `KEEP`,
then `UNDO kind=helper from=30 to=28 want=28`, `LIVE tag=helper_keep
trial=30 undo=ok`, `PAD_M35_LIVE_OK`. Model: 30.

## 中文

M3.5 打磨编辑器并补测试：

- 新命令：`undo`（撤销上一次改字）、`yank`（粘贴上一次剪下/复制的字）、
  `indent` / `dedent`（行首加/减两个空格）、`bob` / `eob`（跳到全文开头/结尾）、
  `set-mark` + `kill-region` / `copy-region`（标记区域后剪切/复制）。
  `kill-line` 现在也会记住剪下的字。
- 每个命令被拒绝时都有小朋友能懂的理由，并带一句 `say="..."`：
  `nothing-to-undo`（还没有可以撤销的）、`nothing-to-yank`（还没剪过东西）、
  `no-mark`（先放一个标记）、`empty-region`（标记和光标在同一处）、
  `no-indent`（行首没有空格）、`already-there`（已经在那儿了）。
  被拒绝的命令绝不改动缓冲区，也不进撤销栈。
- 新的 `SCORE` 行说明分数去哪了；`TAPE` 用 `.` 表示空格、`^` 表示光标。
- 第二个目标（三行）"hi" / "  aura" / "pad"：主助手 28，更差 11 DROP，
  用 undo 的 43 KEEP，用区域剪切的 43 平分 DROP，用 indent 的 45 KEEP。
- **撤销 KEEP**：`pd:helper-undo!` 把上一次 KEEP 换掉的主助手恢复回来，
  重新回放并重新打分（必须和记录一致），没有可撤销时给出 REJECT。
- 测试：括号平衡检查、Python 模型交叉验证、168 项 Soft 单元检查
  （`PAD_TEST_OK`）、三行目标比赛（`PAD_M35_OK`）。`smoke.sh` 仍以
  `PAD_SMOKE_OK` 结束，`PAD_LIVE=0` 无需密钥也全绿。
