# M4: two pads, find / replace, record / play, macro propose

M4 turns Aura Pad into a small story editor for kids. There are two
named pads (`story` and `scratch`). M4 adds **find / replace**, a
**macro recorder** (`rec` / `stop` / `play`), a **buffer-law race** (two
rules race on the same keys) and **macro propose**: an AI (fixture or
MiniMax) proposes a Soft lambda that returns a recorded macro, and Soft
gates it, races it and KEEPs it only if it is strictly better. Every
refusal has a short kid sentence. M0–M3.5 files and numbers are
unchanged. All M4 work lives in new files.

```bash
bash scripts/smoke_m4.sh             # PAREN_OK, PAD_M4_MODEL_OK, PAD_M4_TEST_OK, PAD_M4_OK (+ live if keyed)
PAD_LIVE=0 bash scripts/smoke_m4.sh  # no HTTP, PAD_M4_LIVE_SKIP
bash scripts/smoke.sh                # M0..M3.5 + M4 → PAD_SMOKE_OK
python3 scripts/m4_model.py replace-all:cat=dog switch:scratch end   # score one story macro on the host
python3 scripts/m4_model.py --check  # model re-computes every number m4_test.aura asserts
python3 scripts/propose_minimax.py --macro out/m.lambda 1 note      # one live story macro
```

## The kid story goal

| pad | start | goal |
|-----|-------|------|
| `story` (cursor here) | `a cat` / `the cat ran` | `a dog` / `the dog ran` / `they had fun` |
| `scratch` | `my notes` / `they had fun` | unchanged |

Score is `60 - keys - 2*rejects - 3*letters_off`, where letters off are
counted over both pads, so hurting `scratch` costs points too. The start
is 19 letters off, which scores 3. Typing everything by hand scores 30.
The smart way scores 51: replace all `cat` with `dog` in one key, copy the
scratch line and paste it.

## Pad state (`soft/pad/m4.aura`)

A pad state is `(bufs cur needle rec macro law)`:

- `bufs` is `(("story" edit-state) ("scratch" edit-state))`. Each pad is an
  M3.5 edit state with its own text, cursor, mark and undo.
- `cur` is the pad the keys go to.
- `needle` is the last word found, or none.
- `rec` and `macro`: the recorder is on or off, and the macro holds up
  to 12 accepted tokens.
- `law` is the **buffer law** `(wrap max)`. `wrap 1` means find starts
  again from the top. `max` is the most spots `replace-all` may change at
  once.

`pad:mgate` / `pad:mstep` / `pad:mop` are pure, so scoring is safe inside
fibers. A refused token never changes the state.

| token | does | refused with (kid sentence) |
|-------|------|-----------------------------|
| `find:WORD` | jump to the next WORD at or after the cursor | `empty-needle` "tell me a word to find first", `not-print`, `not-found` "could not find that word" |
| `find-next` | jump to the next spot of the last word | `empty-needle`, `not-found` |
| `replace:NEW` | swap the found word under the cursor for NEW (undo-able) | `empty-needle`, `not-found` (cursor moved away), `not-kind` "let us use kind words", `not-print`, `need-space` |
| `replace-all:OLD=NEW` | swap every OLD in this pad (one undo step) | `not-a-key` (no `=`), `empty-needle`, `not-print`, `not-kind`, `not-found`, `too-many` "that word is in too many spots", `need-space` |
| `switch:NAME` | go to the other pad; the cut / copied text comes with you | `no-buffer` "there is no pad with that name", `already-there` |
| `rec` | start recording keys | `busy-recording` "stop the recording first" |
| `stop` | stop recording | `not-recording` "you are not recording", `empty-macro` "record some keys first" |
| `play` | replay the macro for **one** key; each step is gated again | `busy-recording`, `no-macro` "record a macro first" |
| any key while recording | recorded if accepted | `macro-full` "the macro is full" (12) |

Every M3.5 token (`undo`, `yank`, `set-mark`, `copy-region`, `eob`, …)
works on the current pad. Refused steps inside `play` count as rejects,
and the REJECT line names the first one (`cmd=play reason=not-found`).
Mean words (`stupid`, `dumb`, `hate`, `idiot`, `shut up`) can never be
typed by `replace` / `replace-all`. A macro body that contains one is
refused before any slot is touched.

## Buffer-law race (dual worldline, same keys)

`pad:law-race!` races two laws on the **same** key list, one fiber each.
The keys are `replace-all:a=o eob find:cat replace:dog find-next replace:dog`.

| race | base | trial | result |
|------|------|-------|--------|
| 1 | `stop-3` −8 (find at the end finds nothing; 5 REJECTs) | `wrap-3` 14 (find wraps to the top) | `KEEP kind=law law=wrap-3` and the law is stamped into main |
| 2 | `wrap-3` 14 | `wrap-9` −7 (`replace-all:a=o` is allowed and smashes the story: `o cot` / `the cot ron`) | `DROP kind=law ... say="we keep the old rule, 14 is not beaten"` |

So the `too-many` rule is a safety rule that wins honestly.

## Macro propose (`soft/pad/macro.aura`, `fixtures/m4/`)

The hot slot `pd:macro` holds the trial and `pd:mshadow` the main macro
(`std/hot-strategy` `register!` / `swap!` / `heal!`). Order: body gate
(code words from `hot.aura` + `helper.aura` + `pd:macro`, `pd:mshadow`,
`pad:msim`, `pad:mstamp`, `*m4-`; then kind words), swap, probe the plan
shape (`heal!` on a bad shape), race trial vs main on the story goal with
the main law (`pad:race-thunks!`). KEEP only on a strictly higher score,
otherwise `heal!` + DROP. `pd:macro-undo!` takes back a KEEP with an
honest re-score (it prints `UNDO_FAIL` on a mismatch).

| step | result |
|------|--------|
| main `main.lambda` (types by hand) | `MAIN macro start=30 law=wrap-3` |
| `pd:macro-undo!` with nothing kept | `REJECT mid=4 reason=nothing-to-undo cmd=macro-undo` |
| `bad.lambda` (`set!`) | `GATE reject reason=gate word=set!` |
| `mean.lambda` (`type:you are stupid`) | `GATE reject reason=kind word=stupid say="let us use kind words"` |
| `ugly.lambda` (`#t` token) | `HEAL name=pd:macro reason=probe why=bad-token` |
| `oops.lambda` | REJECT `empty-needle`, `not-found`, `too-many`, `no-buffer` (+2), 18 → DROP + heal |
| `replay.lambda` (`find:cat rec replace:dog find-next stop play` + copy) | 44 → `KEEP ... say="the new macro wins, 44 beats 30"` |
| `smart.lambda` (`replace-all:cat=dog`, copy scratch line, paste) | `RACE macro base=44 trial=51` KEEP |
| `tie.lambda` (another 9-key path) | 51 tie → `DROP ... say="same score, we keep the old macro"` |
| `pd:macro-undo!` | `UNDO kind=macro from=51 to=44 want=44` |
| `smart.lambda` again | `RACE macro base=44 trial=51` KEEP |

`KEEPS=3 DROPS=2 UNDOS=1 LAW_KEEPS=1 LAW_DROPS=1`,
`WORLD line=fiber_live backend=2 joins=14/14`, `PAD_M4_OK`. `fiber_live`
is printed only when every join lands (2 law races + 5 macro races = 14).

TAPE now shows both pads (`*` marks the current one) and a law line:

```
TAPE pad=story* lines=3 text=a.dog|the.dog.ran|they.had.fun view=a.dog|the.dog.ran|they.had.fun^ undo=2 slot=pd:macro
TAPE pad=scratch lines=2 text=my.notes|they.had.fun view=my.notes|they.had.fun^ undo=0 slot=pd:macro
TAPE law=wrap-3 find=none macro=0 kill=|they.had.fun
SCORE total=51 start=60 keys=-9 rejects=-0 dist=-0 say="9 keys, 0 oops, 0 letters off"
```

| layer | file | marker |
|-------|------|--------|

| Soft tests | `soft/pad/m4_test.aura` | `TESTS checks=293 fail=0`, `PAD_M4_TEST_OK` |
| law race + macro race + undo | `soft/pad/m4_smoke.aura` | `PAD_M4_OK` |
| live story macro | `soft/pad/m4_live.aura` | `PAD_M4_LIVE_OK` / `_SKIP` |

`m4_test.aura` covers every new token with REJECT paths (kid reason; the
player skips it: same state, 0 keys, 1 reject) and success paths. It also
covers: replace clears the mark, replace-all clamps the cursor and only
touches the current pad, each pad keeps its own cursor and undo, the kill
text travels between pads, recording skips refused keys, `play` costs one
key and counts inner refusals, the macro is capped at 12, 47 plans shared
with the Python model (`m4_model.py --check` fails if the Soft table
drifts), fixture and law scores, text helpers, kid sentences, the macro
body gate, and M3 / M3.5 scores (27 / 45) unchanged. `smoke_m4.sh`
fails below 250 checks.

## Live (MiniMax, measured 2026-10-05)

`--macro` explains the two pads and the new tokens and pre-checks the
token shape on the host. Unkind words are left to the Soft kind gate. Run 1:
`"switch:scratch" "next-line" "set-mark" "next-line" "kill-region" ...`
→ `REJECT reason=no-line`, `empty-region`, `nothing-to-yank`,
`need-space`, `RACE macro base=30 trial=-18`, DROP + heal,
`PAD_M4_LIVE_OK`. Four more rounds with score feedback in the note
(model scores −13, −36, −38, 10) all stayed below main 30: the AI found
`replace-all:cat=dog` but kept losing points on `bob` / `already-there` and
paste `need-space`, so every one would be an honest DROP. On a live KEEP, `m4_live.aura` also undoes it and
requires main to be back at 30.

## 中文

M4 让 Aura Pad 变成小朋友的“故事编辑器”：

- **两个本子**：`story`（故事）和 `scratch`（草稿）。`switch:scratch`
  切换本子，剪下/复制的字会跟着你走；每个本子有自己的光标和撤销。
- **查找 / 替换**：`find:cat` 找到下一个 cat，`find-next` 找下一个，
  `replace:dog` 把光标处找到的词换掉，`replace-all:cat=dog` 一键全部替换。
  被拒绝时有小朋友听得懂的话：`not-found`“could not find that word”，
  `empty-needle`“tell me a word to find first”，`too-many`“that word is in too
  many spots”（一次最多换 3 处，防止把整篇故事改乱），`not-kind`“let us use
  kind words”（不让输入不友好的词）。
- **宏录制**：`rec` 开始录，`stop` 停，`play` 一键重放（只算 1 个键，里面每一步
  仍要过门卫）。
- **规则赛跑**（同一串按键、两条规则、两条 fiber）：会“从头再找”的 wrap-3
  14 分胜过 stop-3 的 −8 分，KEEP 并写入主世界；一次能换 9 处的 wrap-9 把故事
  改成 “o cot / the cot ron”，只有 −7 分，DROP。
- **AI 提议宏**：fixture 或 MiniMax 提议一个返回“录好的按键列表”的 Soft
  lambda。Soft 先查禁用代码词和不友好词，再检查形状（不对就 heal!），然后和主宏
  在故事目标上赛跑：严格更高分才 KEEP，否则 heal! + DROP。手打 30 分 → 录制重放
  44 KEEP → 一键替换 + 复制粘贴 51 KEEP → 同分 51 DROP → 撤销回 44 → 再 KEEP 51。
- 测试：括号检查、Python 模型对拍、293 项 Soft 检查（`PAD_M4_TEST_OK`）、
  `PAD_M4_OK`。`smoke.sh` 仍以 `PAD_SMOKE_OK` 结束，`PAD_LIVE=0` 不需要密钥。
