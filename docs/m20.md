# M20 who

`apply` keeps one fixture define. `who` says who wrote it. Save, quit,
and open the same path again. Either `who` is still that sentence, or
the pad says `soft-only` because `GAPS persist-global` fired. `undo`
puts the text and the author back together. A DROP writes no sidecar.

```bash
bash scripts/smoke_m20.sh
```

The script runs the native Aura binary. It does not call docker.
It prints `PAD_UNDO_WHO_OK`, `PAD_REOPEN_OK`, and `PAD_M20_OK`.
It does not call a live model. It does not call `pad:time-open!`
or `pad:book-open!`.

## Undo

Sentence `undo`, and byte 26, each take back one KEEP. The page bytes
return to the text from before that KEEP. `who` returns to the same
sentence as before it.

On the keep-hello page, before the KEEP:

```text
CHECK who-before=nobody has changed this yet
```

After `apply keep-hello`:

```text
CHECK who-kept=the AI helper wrote hello: closer (change 2)
```

After `undo`, `who` is `nobody has changed this yet` again. A second
`undo` says `nothing to undo`. The run printed `PAD_UNDO_WHO_OK`.

## Reopen

Sentence `apply keep-hello`, then sentence `who`. The KEEP writes the
projection and the `.aw` while the file child is current. A new process
opens that same path.

This run kept the engine record. `who` before the new process and
`who` after it were the same sentence:

```text
the AI helper wrote hello: closer (change 2)
```

The log had `REOPEN deser=yes`, `REOPEN root=same`,
`REOPEN canary-before=a,b`, `REOPEN canary-after=a,b`,
`REOPEN sane-before=yes`, and `REOPEN sane-after=yes`.
It did not print `GAPS persist-global`.

A reopen that cannot keep the engine record still passes. The log then
contains `GAPS persist-global` and `TITLE deserialize-workspace changed the root or the canary`.
`SAY` contains `soft-only`, and the author word comes from the Soft
row stamp. That path is not a failure. It must not invent a `sum=`.

## Hands-on

`aura-pad FILE` opens on the sentence line. Tab moves between the page
and that line. Type the sentences below, then Enter. Do not call a
function that exists only in a smoke.

1. `apply keep-hello`
2. `who`
3. `save`
4. `quit`
5. Start a new process on the same path. `who` again.

`who` after the KEEP names the helper and `closer`. After the new
process, either that sentence is unchanged, or `SAY` contains
`soft-only` and the log contains `GAPS persist-global`.

`undo` after the KEEP, before quitting, restores the page and the
author together. `PAD_CLASSIC=1` is the old vi map and is not this
scenario.
