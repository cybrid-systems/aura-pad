## Soft Aura syntax highlight (`soft/pad/hl.aura`)

Soft tokenizes a source string into kind tags and a kid-readable **HL
color tape** (one letter per source character). No C paint yet — Soft
owns the tape so AI and kids can read it.

| letter | kind |
|--------|------|
| `P` | paren `(` `)` |
| `K` | keyword (`define` `lambda` `if` `load` `cond` `let` `begin` `set!` …) |
| `S` | symbol |
| `T` | string `"..."` |
| `C` | comment `;` → end of line |
| `Q` | symbol starting with `query:` |
| `M` | symbol starting with `mutate:` |
| `N` | number literal |
| `.` | whitespace / other |

Example demo source and tape (also asserted by Soft + Python model):

```
(define (foo x) ; hi
  (+ x 1))
(query:find "foo")
(mutate:summary)
```

```
HL n=67 toks=20 K=1 Q=1 M=1 C=1 T=1
color=PKKKKKK.PSSS.SP.CCCC...PS.S.NPP.PQQQQQQQQQQ.TTTTTP.PMMMMMMMMMMMMMMP
```

Helpers: `pad:hl-tokens`, `pad:hl-color`, `pad:hl-tape!`, `pad:hl-count`.

## Jump / refs — Soft LSP-lite (`soft/pad/jump.aura`)

Jump state `js = (src point stack)`:

| command | does | kid REJECT |
|---------|------|------------|
| `pad:goto-def` | jump to the Soft `(define NAME` / `(define (NAME` binding; push old point | `no-symbol` "put the cursor on a name first", `no-def` "could not find where that name is born" |
| `pad:find-refs-cmd` | list every token offset of the name under point (skips strings/comments via HL) | `no-symbol`, `no-ref` "that name is not used anywhere else" |
| `pad:jump-back` | pop the jump stack | `nothing-to-back` "nowhere to jump back to" |

Fixture story:

```
(define (hello x) (+ x 1))
(define (bye y) (hello y))
(hello 3)
```

- defs `hello` → `9`; refs → `9.44.55`
- goto-def from `44` → `9` KEEP stack; jump-back → `44`
- cursor on `(` → `no-symbol`; on `+` → `no-def`

This is Soft-buffer analysis (Aura-unique kid pad), not a fake LSP server.

## 中文

M5 给 Aura Pad 加上 **Soft 侧的 Aura 语法高亮、跳转/引用、以及 Soft 能
诚实调用的 query/mutate 原语**：

- **语法高亮**：把 `.aura` / sexp 文本拆成 kind（括号、关键字
  `define/lambda/if/load`、符号、字符串、注释、`query:`、`mutate:`、数字），
  产出小朋友也能读的 HL 色带（每个字符一个字母：`P K S T C Q M N .`），
  还没有 C 画面。
- **跳转 / 引用（Soft LSP-lite）**：`goto-def` 跳到 `(define NAME` /
  `(define (NAME`；`find-refs` 列出所有同名 token（跳过字符串和注释）；
  `jump-back` 退回。拒绝理由是小朋友能懂的话：`no-symbol`“先把光标放在名字上”、
  `no-def`“找不到这个名字是在哪里出生的”、`no-ref`、`nothing-to-back`。
- **query / mutate**：只调用 tip 上真实可用的 Soft 面
  （`query:list-categories`、`query:help`、`(query :find)`、`(query :def-use)`、
  `mutate:summary`、`mutate:boundary-safe?`、`mutate:rebind` 等）。
  tip 没有的名字（`define-lookup`、`query:code`、`query:ref-counts`、
  `query:node-types`）记成 GAPS，并向 `cybrid-systems/aura` 提可改进 issue
  （Filed from: aura-pad），**不编造假 Soft API**。
- 测试：括号检查、Python 模型对拍、≥50 项 Soft 检查（`PAD_M5_TEST_OK`）、
  `PAD_M5_OK`。`smoke.sh` 仍以 `PAD_SMOKE_OK` 结束。
