# M12 — the book closes

Part of [NEXT.md](NEXT.md). Marker `PAD_M12_OK`. Soft tip `c69e644`.

## Kid story

Close the pad, open it again: the story is the same story, and `who`
still answers. Open is restore, not "read text and guess".

## Probe (M12.1)

| Surface | On tip |
|---------|--------|
| `std/persist` / `persist:save` / `persist:load` | **unbound** → `GAPS persist` |
| `serialize-workspace` / `deserialize-workspace` | bound → Soft book path |
| `write-file` / `read-file` | bound → Soft `.pad` sidecar |

No invented Soft persist API. When `std/persist` lands, Soft can swap
the engine path behind the same close/open face.

## Soft path (M12.2)

`soft/pad/book.aura` owns close/open:

1. **Close** `pad:book-close!` → `serialize-workspace` (`.aw`) + Soft
   sidecar (`.pad` via `pad:time-save!`): page rows, who stamps, story
   strip. Say: `the book is closed, with its story`.
2. **Open** `pad:book-open!` → `deserialize-workspace` + sidecar restore
   (no `set-code`). Say: `the book is open: N saved steps…`.
3. **Who** after open uses pad stamps + mutation-log reasons
   ([aura#4365](https://github.com/cybrid-systems/aura/issues/4365),
   [aura#4367](https://github.com/cybrid-systems/aura/issues/4367)):
   reopened records say `author=0`; Soft still agrees.

Play loop does **not** load `book.aura` (key latency unchanged).
