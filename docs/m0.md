# M0 smoke sequence

Deterministic Soft script `soft/pad/m0_smoke.aura`. Seed `20261005`,
24 steps. Dialect string: `live-soft-editor-pad-m0`.

One buffer model. One seeded key stream. Two keymaps. The numbers are
the race. Goal fixture: character codes for `"hi aura"`.

## Law

1. Seed step: `(modulo (+ (* seed 75) 74) 65537)`. The first word is
   `34567`. Each step uses one word, then steps.
2. From word `r`: op = `r mod 6`, arg = `r / 6`.
   Ops: `0` left, `1` right, `2` insert-letter, `3` delete-back,
   `4` insert-space, `5` end (gentle) / home (bold).
3. Insert-letter writes `97 + (arg mod 26)` (a–z).
4. Gate, kid-friendly reasons:
   - gentle left at point 0 or right at end → `too-far`
   - delete-back at point 0 → `empty-line`
   - insert when `len >= max` → `need-space` (gentle max 8, bold max 20)
   - gentle insert with `(arg mod 30) > 25` → `not-print`
5. Rejected commands never mutate the buffer.
6. Score = `edits_ok - 2 * rejects - distance_from_goal`.
   Distance is length-gap plus positional mismatches against `*goal*`.

## Strategies

Neither keymap calls `set-code`. M0 does not `hot-strategy:register!`
them. M1 will swap keymap packs mid-run.

## Race

Same seed, both keymaps. Race thunks only return a score. They do not
`set!` the main buffer, so a real fiber cannot publish the loser's
buffer into the live world.

`fiber:spawn` both thunks, then `fiber:join`. `fiber_live` only when the
ids are distinct and positive, both joins are numbers, `joins` equals
`spawned`, and `fiber:spawn-backend` is `> 0`. Otherwise the thunks run
on the host and the stamp is `host-sequential`.

After the race a pure host audit pass replays both keymaps with the gate
log on. It prints the first three `REJECT` lines per strategy and the
`REJECTS` totals. It writes no world slot.

The strictly higher score wins (`higher-score-stamp` /
`lower-score-rollback`). A tie would KEEP gentle (`tie-keep-gentle-stamp`).
This seed is not a tie.

The winner is replayed with the tape on and stamped into the main buffer.
The loser is not stamped. That is the rollback.

Gentle moves are careful but the gate rejects `too-far` / `not-print`
often, so its score lags. Bold clamps moves, inserts more freely, and
wins after one `empty-line` reject.

`backend=2` is the CLI thread fallback, not serve-async. If a future
binary joins nothing, the same script must print `host-sequential` and
must not print `fiber_live`. The smoke accepts either honest line.
`fiber_live` without `joins=2/2` is a failure.

The smoke also checks the gate on four hand-built states: `too-far`,
`empty-line`, `need-space`, `ok`.
