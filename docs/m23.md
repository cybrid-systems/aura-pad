# M23 a child story

A `.story` or `.txt` page opens as sentences. The screen does not
show `define`. The same card and the same undo apply. A refusal on
a story is at most eight words.

```bash
bash scripts/smoke_m23.sh
```

The script runs the native Aura binary. It does not call docker.
It does not set `PAD_CLASSIC`. It prints `PAD_STORY_OPEN_OK`,
`PAD_STORY_DEF_OK`, `PAD_STORY_WHY_OK`, `PAD_STORY_TX_OK`,
`PAD_STORY_KIND_OK`, and `PAD_M23_OK`.

## Hands-on

Open `note.story`. The title says `story`. Type three sentences:

```text
the cat sat
the cat ran
the cat slept
```

The sentence line is `make the last line kinder`. Offline, that
selects `soft/pad/fixtures/story_kinder.txt`. The kind line rewrites
only the last sentence to `the cat dreamed`. The first two sentences
stay. KEEP writes that sentence and stamps the row helper.

`undo` puts the three sentences and their authors back to
`nobody.nobody.nobody`. Drop writes nothing.

The same fixture also has `the stupid cat`. The gate says `not-kind`.
SAY is `let's use kind words`, which is four words. The three
sentences stay.

`code` on this page says `not aura code`. `story` on a sexp page
says `not a story`.

## Child workspace

The three sentences become `s1`, `s2`, and `s3` in a child workspace
after that child's set-code. `pad:tx-gate` then treats those names as
born and does not say `no-def`. The projection rows stay the sentences.
A type refusal on the story does not say `type error`. An aura page
may keep the engine text.

## What this step does not do

It does not update `docs/tutorial.md`. It does not ask the child to
press `ctrl-x`. It does not call a live model.
