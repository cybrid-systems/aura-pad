# M8: kid onboarding card + intent worldline

M8 is the kid-facing game. Soft shows a welcome card on the first play
frame; the kid gives a goal (`goal:hi aura`); two command helpers race on
fibers toward that goal; Soft prints story `CARD` lines; the strictly
higher score is KEEP, a tie is DROP + `heal!`; undo KEEP re-plays and
re-scores (a forced mismatch fails loud as `PAD_M8_UNDO_FAIL`). C only
prints SAY / Soft log text — it never picks the winner.

```bash
bash scripts/smoke_m8.sh             # PAD_M8_MODEL_OK, PAD_M8_TEST_OK, PAD_M8_PLAY_OK, PAD_M8_OK
PAD_LIVE=0 bash scripts/smoke.sh     # M0..M8 → PAD_SMOKE_OK
python3 scripts/goal_model.py --check
```

## Score and cards

Story score (same shape as M3, plus an unkind slot kept at 0 because the
kind-word gate refuses mean bodies before they enter `pd:goal`):

```
40 - keys - 2*rejects - 3*dist - 4*unkind
```

Default goal `"hi"` / `"aura"`. Main helper scores 27 (`hi|au`); better
scores 31 (`hi|aura`). Soft prints:

```
CARD a=27 b=31 KEEP=b say="b is closer"
```

Tie → `KEEP=a say="same score, keeping yours"` and DROP reason=`tie`.

## Gate

- Banned words (hot.aura + goal banned) → `GATE reject reason=gate`
- Unkind words (`stupid` …) → `GATE reject reason=kind`
- `exec` / `network` / `ffi` when `capability?` is bound →
  `REJECT reason=not-allowed`; if unbound, Soft would print
  `GAPS capability` and keep the word list (tip has `capability?`)
- Ugly plan shape → `HEAL` + probe why

## Play path

`play.aura` loads `card.aura` only (not the full goal stack), so the M7
key path stays light. First SAY is the welcome card. `KEY goal:` with
empty text rejects with "tell me what the page should say"; `KEY goal:hi
aura` sets the goal string into SAY. Fixture races live in `goal.aura`
(smoke / propose).

## KEEP / DROP

KEEP: welcome card on first frame; `goal:` empty refuse; fixture worse
DROP+HEAL, tie DROP, better KEEP with page=`hi|aura`; capability
`not-allowed`; undo KEEP restores score 27; mismatch fails loud.
DROP: loading the full play stack and `goal.aura` in one Soft process
(tip Soft nested `substring` in that load order is unsafe — stacks stay
separate).

## 中文

M8「欢迎卡 + 意图世界线」：打开 pad 先看到两行欢迎词；孩子用
`goal:hi aura` 给出目标；两条命令助手在 fiber 上赛跑；Soft 打印
`CARD a=.. b=.. KEEP=..`；严格更高分 KEEP，平局 DROP 并 `heal!`；撤销
KEEP 会重跑打分，对不上就大声失败。门卫拦截禁用词、不友善词，以及
`capability?` 绑定后的 exec/network/ffi。C 只负责把 SAY 打出来，不选
赢家。
