# M1 — hot keymap pack swap/heal and an honest worldline

`soft/pad/m1_smoke.aura` → `PAD_M1_OK`. Seed `20261005`. M0 is unchanged:
`m0_smoke.aura` does not load `pack.aura` or `hot.aura` and still races
gentle vs bold without `hot-strategy`.

```bash
bash scripts/smoke_m1.sh   # PAD_M1_OK
```

## Keymap pack

A pack is `(step room strict)` (`soft/pad/pack.aura`):

| field | range | meaning |
|-------|-------|---------|
| `step` | 1..8 | cursor jump for left/right, clamped at the edges |
| `room` | 1..32 | max buffer length before insert says `need-space` |
| `strict` | 0/1 | 1 = gentle rules (`too-far`, `not-print`, key 5 = end); 0 = bold rules (clamp, any letter, key 5 = home) |

`map-gentle ≡ (1 8 1)` and `map-bold ≡ (3 20 0)`. The pack sim replays M0
exactly: `PACK_GENTLE=-2`, `PACK_BOLD=9`.

## What M1 guarantees

1. `pd:law` is a real `std/hot-strategy` slot. Seed is `set-code` +
   `eval-current` + `hot-strategy:register!`. Later bodies go in with
   `hot-strategy:swap!`; `hot-strategy:heal!` restores the snapshot. The
   body is `(lambda () (list step room strict))`.
2. The slot changes **mid-run** on the live editor buffer (one key at a
   time, `pad:live-key!`):
   - 10 keys on the seed gentle pack `(1 8 1)`.
   - A body with `set!` is gate-rejected: `GATE reject reason=gate word=set!`.
     Key count stays 10, slot stays `(1 8 1)`.
   - `SWAP name=pd:law key=10 reason=mid-swap` installs `(2 12 0)`.
   - 5 more keys on that pack (key 15). Earlier keys are not retconned.
   - An ugly body `(lambda () (list 2 12))` swaps in, fails the pack probe,
     and `heal!` runs: `HEAL name=pd:law key=15 reason=probe`. The slot is
     back to `(2 12 0)` (last good, not the seed).
3. At live key 8: `MUTATE key=8 room-boost=2 slot=pd:law` (two more
   letters of room for the rest of the live run). A Soft world mutation
   log, not `mutate:rebind`.
4. Kid-friendly reasons stay. Live rejects print
   `REJECT mid=0 reason=too-far|not-print|empty-line|need-space key=N slot=pd:law`
   (`mid=0` is the live hot slot).
5. The dual race is still `map-gentle` vs `map-bold` on the same seed.
   `KEEP` / `DROP` go to the strictly greater score; a tie keeps gentle.
6. `fiber_live` only when the race spawned two distinct positive fiber
   ids, both `fiber:join`s returned numbers, and `fiber:spawn-backend > 0`.
   Otherwise the same thunks run on the host and the line is
   `host-sequential`.

future binary returns `#f` from spawn or join, the smoke still passes with
`host-sequential` and must not print `fiber_live`.

跑：前 10 键用温柔包 `(1 8 1)`；带 `set!` 的坏代码被门卫拒绝；第 10 键
